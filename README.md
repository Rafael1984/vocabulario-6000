# vocabulario-6000


Neste site você estuda as 6.000 palavras mais frequentes do inglês, em 60 lições de 100 palavras. Se você trabalha com segurança, as lições bônus B1 a B30 trazem 1.500 termos e expressões de Cloud Security e Cybersecurity.

Acesse: https://english.cloudsecstudy.com.br

## Como estudar

Em cada lição você lê um texto que usa as palavras da lição e vê uma frase de exemplo para cada uma. Passe o mouse sobre uma palavra para ver a tradução dela naquela frase. Ao dar play, você ouve uma voz neural e acompanha a frase destacada na tela.

Quando você marca uma palavra como "Sei", ela vira um ponto no cérebro 3D. As palavras que você marca como "Não sei" vão para a lista Minha revisão. Na aba Praticar você treina em rodadas e, se quiser, leva os flashcards para o Anki.
